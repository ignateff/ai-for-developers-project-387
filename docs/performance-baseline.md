# Performance Baseline

These are the accepted performance targets for Lighthouse audits.

| Metric | Target | Good Threshold |
|--------|--------|----------------|
| LCP | ≤ 2500 ms | ≤ 2500 ms |
| CLS | ≤ 0.1 | ≤ 0.1 |
| INP | ≤ 200 ms | ≤ 200 ms |

A metric is considered degraded when its measured value exceeds the target by more than 10%.
