# Actions budget experiment (#41)

`scripts/actions-budget.ts` is a local simulation, not an admission gate. It always returns `decision: infra`; `hypothetical` and evidence links illustrate a calculation under assumed inputs, not permission to run a model. Nothing connects it to a workflow or runtime.

The caller supplies a workflow ID, a boundary run ID and a run-to-PR/budget binding for every run from that boundary. These bindings are hypothetical: event classification is not authentication, author trust, or proof of historical event identity. In particular, Actions `pull_requests`, default-branch SHA and titles are not used as PR identifiers. Run-ID ordering and the continued presence of the boundary do not prove history is complete or establish a safe migration boundary. Retention or administrative deletion can erase runs; administrators can change workflow configuration and permissions. Missing bindings, API errors, incomplete pagination and ambiguous model markers fail closed.

The simulation counts successful `model` job `admission` steps per distinct job ID, separately by PR and budget, across run attempts. A reused job ID is counted once; a new model job on a rerun is counted again. The tests mock these properties; they do not establish that GitHub's partial rerun API has these semantics, that the marker survives cancellation, or that marker creation is atomic with admission. Job results after admission do not change the count. No lock or serialization is implemented: concurrent calculations are not a safe reservation. A publication-only rerun, author trust, actual event binding, cancellation behavior, old history, and token permissions—including exchanged App tokens—still require independent proof.

No metadata-only Actions runs, model calls, workflow enabling, or permission changes are authorized by this experiment. With no separately approved metadata-only runs and token verification, issue #41 remains blocked; do not use this output to enable dependent model contours. External storage would require a new human decision.
