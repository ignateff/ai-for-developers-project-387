# Calendar project history

## Migration boundary

The application was copied from [project 386](https://github.com/ignateff/ai-for-developers-project-386) at commit [`e7c14bb29175882ad5bee7de542b8702333ebe63`](https://github.com/ignateff/ai-for-developers-project-386/commit/e7c14bb29175882ad5bee7de542b8702333ebe63). Its working tree was clean. Application code, contract/generated artifacts, Dockerfile, tests and visual baselines, linters, workflows, agent instructions/skills, design references and domain documents were preserved.

The new tracker is [project 387 Issues](https://github.com/ignateff/ai-for-developers-project-387/issues). Git history, issues, releases, repository protection, GitHub App installations, secrets, dependencies, databases and temporary files were not copied. Historical issue links and changelog entries intentionally retain project 386 URLs. Historical reports describe their original revision, not a new CI run or current issue status.

The existing project 387 Hexlet workflow is unchanged. Release Please requires a new-repository App setup; until configured, only release automation is skipped. See [release configuration](../release.md).
